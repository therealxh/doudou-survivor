# 豆豆幸存者（Doudou Survivor）

一个 **2.5D 俯视角 Roguelike 生存割草 Demo**（Unity 2022.3 · URP）——在怪潮中活过 **10 分钟**。

## 玩法

- 移动躲避 + 武器**全自动攻击**；击杀敌人掉落经验宝石，升级触发**三选一强化**
- **6 种武器**（飞刀→进化弩枪 / 大蒜 / 手雷 / 环绕飞刃 / 回旋镖）× **4 种被动**（攻击/移速/生命/拾取），自由构建
- 活过 10 分钟获胜；死亡或胜利后结算成绩（时间 / 击杀 / 等级），一键重开

## 操作

`WASD` / 按住屏幕拖动（虚拟摇杆）移动——武器自动攻击，无需额外操作。

## 技术要点

| 主题 | 实现 |
|---|---|
| **性能三件套** | 对象池（Stack 复用、预热）· 手算圆形碰撞（距离平方、零物理依赖）· 空间哈希（1m 分格、每帧末重建、零分配查询） |
| **全代码构建** | 零资产手术：`RuntimeInitializeOnLoadMethod` + `sceneLoaded` 订阅，每次场景加载（含重开）自动重建全部对象，不修改任何场景/预制体 YAML |
| **2.5D 表现** | 直立 Sprite + 落地阴影 + flipX 朝向；AI 生成素材 + Python 批处理流水线（抠图/裁剪/缩放） |
| **成长系统** | 委托式升级选项池 + 时停三选一面板（升级曲线递增设计：前小后大） |
| **UI 工程** | 置顶子 Canvas 弹窗模式（overrideSorting + 独立射线器）；真实点击路径（RaycastAll + 指针事件）验收规范 |
| **性能验证** | 300 怪压力实测：渲染增量 ~1.2ms/帧、SetPass 38~51、GC 峰值砍半——基线与对比数据见 `docs/perf/` |

## 构建运行

1. Unity 2022.3 打开工程（首开会自动拉取依赖包）
2. `File → Build Settings → Build`（Windows x64，竖屏）
3. 或直接运行 `Builds/` 下的可执行文件 / Releases 附件

## 开发方式说明

本项目为 **AI 结对开发实验**：AI 主导代码与素材实现，开发者负责设计决策、手感调参、验收与迭代把关。开发过程保留完整文档（`docs/思路记录/`），每一项技术决策的取舍与踩坑均有记录——用于展示工程方法论与"驾驭 AI 工具链"的实践能力。
